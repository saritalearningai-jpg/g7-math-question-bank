## How to Use

Open `grade7_math_question_bank.csv` in Excel or Google Sheets.
Filter by `unit_number` to get questions for a specific unit.
Filter by `question_type` to select MC, Short Answer, or Word Problem.
Filter by `difficulty` to choose Easy, Medium, or Hard.
